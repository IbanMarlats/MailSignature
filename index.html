Comment installer ma signature ?
1
Copiez votre signature

Cliquez sur le bouton Copier la Signature (Visuel) ci-dessous. La signature est maintenant dans votre presse-papier.

2
Ouvrez les paramètres Gmail

Dans Gmail, cliquez sur l'icone Paramètres (roue dentée en haut à droite), puis Voir tous les paramètres.

3
Allez dans l'onglet Signature

Restez dans l'onglet Général, puis descendez jusqu'à la section Signature. Cliquez sur Créer pour ajouter une nouvelle signature (ou modifiez la signature existante).

4
Collez votre signature

Cliquez dans la zone de texte de la signature, puis collez avec Ctrl + V (ou Cmd + V sur Mac).

5
Enregistrez

Descendez tout en bas de la page et cliquez sur Enregistrer les modifications. Votre signature apparaitra automatiquement dans vos prochains e-mails.

Copiez votre signature

Cliquez sur le bouton Copier la Signature (Visuel) ci-dessous. La signature est maintenant dans votre presse-papier.

2
Ouvrez Outlook Web ou Desktop

Web : Cliquez sur la roue dentée Paramètres en haut à droite, puis Courrier > Rédiger et répondre.
Desktop : Allez dans Fichier > Options > Courrier > Signatures.

3
Créez ou modifiez une signature

Cliquez sur Nouvelle signature (ou sélectionnez la signature existante à modifier). Donnez-lui un nom.

4
Collez votre signature

Cliquez dans la zone d'édition de la signature, puis collez avec Ctrl + V (ou Cmd + V sur Mac).

5
Enregistrez

Cliquez sur Enregistrer. Pensez à définir cette signature par défaut pour les nouveaux messages et/ou les réponses/transferts.
